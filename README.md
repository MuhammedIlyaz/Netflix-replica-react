# Netflix Replica React

A responsive Netflix-inspired user interface built with React and CSS. This project was created to practice core React concepts such as components, props, state, forms, conditional rendering, and responsive design.

## Features

- Netflix-inspired hero section
- Responsive navigation bar
- Trending movie cards
- Reusable React components
- "More Reasons to Join" section
- Interactive FAQ section
- Email membership form
- Responsive mobile and tablet design
- Custom footer
- Netflix-style visual effects and layout

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
